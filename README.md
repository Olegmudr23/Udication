# Зубодоро

Небольшой помодоро-таймер с зубом на Next.js, React и TypeScript.
Работает полностью в браузере. Результат сборки — статические файлы в `out/`.

## Локальный запуск

Нужен Node.js 22.18+ или 24 LTS.

```sh
npm ci
npm run dev
```

Откройте http://localhost:3000. Если порт занят, Next.js напечатает другой адрес.

```sh
npm test
npm run typecheck
npm run build
```

Для браузерных проверок на запущенном приложении (порт 3000):

```sh
npx playwright install chromium
npm run test:e2e
```

## Публикация в Timeweb Cloud App Platform

1. Загрузите исходники вместе с `package-lock.json` в GitHub, GitLab или Bitbucket. `node_modules`, `.next` и `out` в репозиторий не добавляются.
2. В Timeweb Cloud откройте **App Platform → Создать**, подключите репозиторий и выберите ветку.
3. Выберите тип **Frontend / Next.js**. **SSR оставьте выключенным**.
4. Выберите Node.js **24** (если доступен) или **22**. В расширенных настройках укажите:

| Параметр | Значение |
| --- | --- |
| Команда сборки | `npm run build` |
| Директория сборки | `out` |
| Путь до директории проекта | Корень репозитория, оставить пустым |
| Системные зависимости | Не нужны |
| Переменные окружения | Не нужны |
| Команда запуска | Не нужна для статического frontend |

5. Запустите деплой. После сборки сайт будет доступен на техническом домене из панели Timeweb. При желании подключите свой домен.

Timeweb устанавливает npm-зависимости перед сборкой. Если вместо Next.js выбрать тип HTML/CSS/JS, платформа ожидает уже собранные файлы и не выполняет сборку. Для исходников этого проекта используйте Next.js.

## Поведение таймера

- Фокус: 25 минут; короткий перерыв: 5; длинный: 15 (настраивается от 15 до 30). Длительность меняется в настройках на паузе.
- После каждого четвёртого завершённого фокуса — длинный перерыв. Пропуск не добавляет результат в статистику.
- Автозапуск следующего интервала и звуковой сигнал настраиваются отдельно.
- Задача, настройки, дедлайн и статистика сохраняются в `localStorage` этого браузера. При открытии нового дня дневные счётчики обнуляются; цикл сохраняется.
- История завершённых рабочих интервалов и перерывов хранится там же: тип, длительность, дата окончания и задача на момент старта рабочего интервала. Историю можно фильтровать; она сохраняется после перезагрузки и не обнуляется вместе с дневной статистикой. Пропущенные и сброшенные интервалы в историю не попадают.
- По окончании интервала появляется уведомление «Время вышло!» до его закрытия пользователем; если звук включён и разрешён браузером, воспроизводится сигнал.
- При сворачивании вкладки отсчёт опирается на время окончания. При возвращении или перезагрузке просроченный интервал засчитывается один раз; следующий интервал начинается с момента возвращения, если включён автозапуск.
- Закрытая вкладка не воспроизводит сигнал. Во время сна устройства браузер может отложить сигнал до возвращения. Синхронизации между вкладками и устройствами нет.
- Шрифт системный, иллюстрация и иконки входят в сборку, внешние сервисы и сервер не требуются.
